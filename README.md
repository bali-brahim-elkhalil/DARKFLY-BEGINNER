🦅 DARKFLY Beginner

A simple defensive cybersecurity toolkit built with Python.

DARKFLY Beginner is a lightweight command-line toolkit designed to help beginners explore basic system information, network diagnostics, DNS resolution, and essential security utilities.

✨ Features

- System Information: Display operating system, architecture, hostname, and Python version.
- Network Diagnostics: Check basic DNS resolution.
- DNS Check: Resolve domain names and display their IP addresses.
- Internet Connectivity: Test whether an HTTPS connection can be established.
- Security Basics: Check for common security tools installed on the system.
- Tools Manager: Initial placeholder for future tool management features.

🖥️ Supported Platforms

- Kali Linux
- Linux distributions
- Termux (Android)
- Other Python-compatible environments

Platform compatibility depends on the available Python environment and permissions.

📋 Requirements

- Python 3
- Internet connection for network-related checks

🚀 Installation

Clone the repository:

git clone https://github.com/YOUR-USERNAME/DARKFLY-BEGINNER.git

Enter the project directory:

cd DARKFLY-BEGINNER

Run DARKFLY:

python3 darkfly.py

📱 Termux Installation

Install Python and Git:

pkg update && pkg install python git -y

Clone the repository and run it:

git clone https://github.com/YOUR-USERNAME/DARKFLY-BEGINNER.git
cd DARKFLY-BEGINNER
python darkfly.py
